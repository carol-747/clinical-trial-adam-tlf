Kaplan–Meier estimates; Cox model with treatment as the only covariate.

**Proportional hazards check (scaled Schoenfeld residuals):** global p =
0.598.

Table 14.3.1 counts 151 patients with a dermatologic TEAE, while this
table counts 148 events. The difference is by design: TEAEs include
onsets up to 30 days after the last dose, but the primary endpoint
counts only events during treatment (SAP section 4.4).
